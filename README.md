# AI Governance Is Not What You Think

## Core Thesis
AI governance is not enforcing rules.

It is shaping probability distributions over outputs.

---

## The Mechanism

AI systems generate outputs based on:

P(y | x)

This means:
- No rule execution
- No true reasoning
- Only statistical likelihood

---

## What Governance Actually Does

- Shapes training data  
- Tunes reward models  
- Uses RLHF  
- Applies optimization  

This does not enforce behavior.

It makes certain outputs more likely.

---

## Key Insight

We are not controlling decisions.
